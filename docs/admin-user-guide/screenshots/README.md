# Ảnh chụp đã duyệt

Thư mục hiện chưa có ảnh ứng dụng. Chỉ đặt PNG thật đã được kiểm tra quyền riêng tư tại đây. Không lưu mật khẩu, cookie, token, trạng thái phiên đăng nhập, ảnh gốc nhạy cảm hoặc dữ liệu kinh doanh riêng tư.

Tên ảnh và trạng thái được quản lý trong `../screenshot-checklist.md`. Chỉ ảnh ở trạng thái **Đã kiểm tra** mới được nhúng tài liệu Word. Không dùng ảnh giả hoặc ảnh tái dựng giao diện.
